# AgroConecta

Projeto acadêmico demonstrativo para a prática de Gerenciamento de Configuração de Software.

## Objetivo
Organizar informações básicas de atividades agrícolas, permitindo registrar uma atividade, seu responsável e seu status.

## Estrutura inicial
- `main.py`: exemplo simples de execução do sistema.
- `docs/requisitos.md`: requisitos iniciais do projeto.

## Como executar
É necessário ter Python 3 instalado. No terminal, execute `python main.py`.

## Controle de versão
Este projeto será armazenado em um repositório GitHub para demonstrar clonagem, alteração, criação de artefatos e publicação das mudanças.

## Atualização da prática
Repositório atualizado localmente durante a atividade
de gerenciamento de configuração de software.
