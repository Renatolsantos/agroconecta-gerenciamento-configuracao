# Requisitos iniciais - AgroConecta

## Objetivo
Apoiar pequenas e médias propriedades rurais no registro e acompanhamento de atividades agrícolas.

## Requisitos funcionais iniciais
1. Registrar uma atividade agrícola.
2. Armazenar o nome da atividade.
3. Informar o responsável pela atividade.
4. Apresentar o status da atividade.

## Requisitos não funcionais
1. Código organizado e documentado.
2. Artefatos mantidos em repositório compartilhado.
3. Alterações registradas por controle de versão.
